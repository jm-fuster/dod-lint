Slots

Slots, audited both ways

  • In components: slot properties with no layer, slots without auto layout, default content over its limits.
  • In instances: slots left empty, overfilled or with content outside the preferred instances.
  • Content placed in a slot is checked like any other layer. Default content is checked once, in its component.

Safe fixes

Fixes with a single right answer

  • Binds the variable that already has the exact value, from the file or a library it uses.
  • The same finding in 18 variants is one row and one fix.
  • Removes references that no longer resolve.
  • Each batch is a single undo step, and you can undo it from the plugin.

Variables & modes

Every mode in one audit

Inside components, text contrast is checked in every mode its colors depend on: light and dark, roles, brands. The finding says which mode fails. Screens are checked in the mode they have.
